SDK ДЛЯ ВАШИХ ПРОЕКТОВ

Ассеты из одного места.

Конструктор экспортирует персонажа как один model.glb и инструкцию assembly.json. GLB можно открыть в совместимом движке или редакторе. SDK дополнительно позволяет читать опубликованные каталоги ассетов с проверкой размера и SHA-256.

Установка SDK

python -m pip install -e /path/to/monster-forge

SDK использует только стандартную библиотеку Python. Конструктор и сервер для чтения локального каталога не требуются.

Python

from monster_forge_sdk import AssetStore

# Каталог содержит media/catalog.json и указанные в нём файлы.
assets = AssetStore("/path/to/asset-release")
for asset in assets.list("character"):
    model_path = assets.path(asset.id)  # проверяет размер и SHA-256

# Сохранённый URI также проходит проверку каталога.
path = assets.resolve_uri(file_reference.uri)

Контракт

Метод Результат
list(kind) Ассеты: character, icon, decoration, terrain
get(id) Метаданные и доступные роли файлов
path(id, role) Проверенный абсолютный путь к файлу
read(id, role) Байты с проверкой размера и SHA-256
resolve_uri(uri) Проверенный файл по сохранённому URI каталога
icon_style() Сохранённый промпт с проверенными исходниками

HTTP

GET /api/assets/v1/catalog?kind=icon
GET /api/assets/v1/catalog?kind=decoration
GET /api/assets/v1/catalog?kind=character
GET /api/assets/v1/catalog?kind=terrain
GET /api/assets/v1/icon-style
GET /media/<path из files>

Каталог имеет явную версию схемы и идентификатор релиза. Неизвестные версии, отсутствующие файлы и изменившиеся контрольные суммы вызывают ошибки. HTTP выдаёт только файлы, перечисленные в каталоге.
