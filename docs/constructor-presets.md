# Пресеты конструктора

Пресеты входят в открытую поставку конструктора вместе с существующими частями
и расами. Для их использования не нужны другие проекты или внешняя библиотека.

Все поставляемые пресеты находятся в `config/constructor_presets/v1/`:
один JSON на персонажа с полным набором настроек. Например,
`mom_rpg/classes/mage.json` — один из сохранённых пресетов мага; исторический id
сохранён для совместимости настроек. `index.json` задаёт состав библиотеки,
назначение пресетов и их порядок; эти категории не создают дополнительных
групп деталей в интерфейсе.

Конструктор и команды сборки читают эту библиотеку через
`monsterforge.constructor_presets.load_presets()`. Для изменения персонажа
редактируется его JSON. Новому пресету нужен отдельный файл и запись в индексе.
Описаний персонажей и наборов значений по умолчанию в Python-пресетах больше нет.

Формат файлов и индекса имеет `schema_version: 1`. Вложенные `settings` содержат
собственную версию схемы конструктора; существующие миграции настроек применяются
при чтении, без перезаписи источника. Неподдерживаемые версии, неизвестные поля,
невалидные детали и расхождения с индексом приводят к явной ошибке.
Первоначальный перенос из Python сохраняет все настройки и порядок пресетов.

Публикация создаёт отдельную неизменяемую ревизию: инструкцию сборки версии 2
и один запечённый GLB в `media/assemblies/`. Инструкция содержит снимок настроек
на момент публикации. Изменение пресета не переписывает готовую модель и её
историю: для обновления модели нужна повторная сборка. Промежуточные файлы
и превью остаются в `/tmp/monster-forge`.

Проверить всю библиотеку без пересборки моделей:

```sh
.venv/bin/python -c "from monsterforge.constructor_presets import load_presets; print(len(load_presets()))"
```
